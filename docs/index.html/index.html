Password Checker

A Python project focused on checking password validity and practicing software testing and GitHub collaboration.

Project Features

  • Password length validation
  • Automated tests using pytest
  • Continuous integration with GitHub Actions
  • Common-password check

How to Run

Install dependencies with pip install -r requirements.txt, then run python -m pytest.
